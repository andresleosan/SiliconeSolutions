## Requirements

- Node.js
- Corepack enabled
- pnpm exactly `11.21.0`, invoked through Corepack

## Local Development And Static Export

Install dependencies:

```sh
corepack pnpm install
```

Run the development server:

```sh
corepack pnpm run dev
```

Build the static export and serve the generated `out` directory:

```sh
corepack pnpm run build
corepack pnpm start
```

The static server listens at `http://127.0.0.1:4173` by default.
